# Ejercicio 1: Calculadora Básica

## Descripción
Este programa solicita al usuario **dos números enteros** y calcula de forma automática los resultados de su **suma, resta, multiplicación y división**.

La interfaz cuenta con tres acciones principales:
* **Calcular:** Procesa los números ingresados, valida que sean enteros válidos (evitando errores como la división entre cero) y muestra los cuatro resultados.
* **Limpiar:** Borra las entradas de texto y reinicia los campos de resultado.
* **Salir:** Cierra la aplicación.
